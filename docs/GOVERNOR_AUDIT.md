# Governor Semantic Audit (Phase 4A)

Audit only: **no production registry rows, no module-owner bit, no controller
or bridge SQL change.** Generated by `python -m civ6x10 audit-governors`
(`civ6x10/governors.py`); machine-readable decisions in
`civ6x10/rules/governor_audit.yml`, inventory + relationship graph in
`data/local/governor_effects.csv` / `data/local/governor_graph.json`
(local-only, gitignored like every other extracted dataset).

## Discovery: the whole Governor object, not just promotion modifiers

Schema scan of the official DB (428 tables) found every governor-keyed table:

| table | key | rows | audited |
|---|---|---|---|
| `Governors` | GovernorType | 8 | yes |
| `Governors_XP2` | GovernorType | 1 | yes |
| `GovernorsCannotAssign` | GovernorType | 0 | yes |
| `GovernorModifiers` | GovernorType | 0 | yes |
| `GovernorPromotions` | GovernorPromotionType | 48 | yes |
| `GovernorPromotionSets` | GovernorType | 48 | yes |
| `GovernorPromotionModifiers` | GovernorPromotionType | 75 | yes |
| `GovernorPromotionPrereqs` | GovernorPromotionType | 48 | yes |
| `GovernorPromotionConditions` | GovernorPromotionType | 0 | yes |
| `SecretSocieties` | GovernorType | 0 | yes |

Plus the reachable definition layer: `Modifiers`, `ModifierArguments`,
`DynamicModifiers` (56 governor-carrier modifier types, 0 unmapped),
`ModifierStrings`, `TraitModifiers` (Ibrahim ->
`TRAIT_LEADER_SULEIMAN_GOVERNOR`), `Requirements`
(874) / `RequirementArguments` (846) / `RequirementSets` (863) /
`RequirementSetRequirements` (1556).

Reachability graph: root Governor -> promotion set -> promotion ->
`GovernorPromotionModifiers` -> `Modifiers` -> `ModifierArguments` (numeric)
+ `DynamicModifiers` effect + owner/subject `RequirementSet*` chains;
`EFFECT_ATTACH_MODIFIER` is followed one level (Guildmaster builder charges),
and capability modifiers with **no** arguments (Affluence copy-luxuries,
Foreign Investor copy-strategics) are accounted for explicitly.

## Secret Societies: same framework, mode-gated (reported separately)

`SecretSocieties` is **empty in the clean DB copy**: the four societies are
inserted only when `GAMEMODE_SECRETSOCIETIES` is active, from
`DLC/Ethiopia/Data/Ethiopia_SecretSocieties_MODE.xml` (New Frontier Pass,
`UpdateDatabase id=EthiopiaGameplayXP1_MODE criteria=Ethiopia_Mode`).
They are ordinary Governors on the same promotion framework
(`GovernorPromotionSets` + 4 promotions each, levels 0-3), and that XML also
raises `MAX_GOVERNOR_APPOINTMENTS` to 9.

| society | GovernorType | IdentityPressure | promotions | revenue |
|---|---|---|---|---|
| Owls Of Minerva | `GOVERNOR_OWLS_OF_MINERVA` | 10 | 4 | mode-gated DLC/Ethiopia |
| Hermetic Order | `GOVERNOR_HERMETIC_ORDER` | 10 | 4 | mode-gated DLC/Ethiopia |
| Voidsingers | `GOVERNOR_VOIDSINGERS` | 10 | 4 | mode-gated DLC/Ethiopia |
| Sanguine Pact | `GOVERNOR_SANGUINE_PACT` | 10 | 4 | mode-gated DLC/Ethiopia |

Two rows reachable only through society **unit abilities** (not promotions)
are recorded as an out-of-graph side path rather than dropped:
`SPREAD_DISSENT_LOYALTY_DAMAGE` (Amount 10,
`EFFECT_ADJUST_UNIT_DIRECT_LOYALTY_DAMAGE`, Voidsinger) and
`CULTIST_RELIC_ON_DEATH`. One shipped-XML typo was normalised
(`ModifierID` -> `ModifierId`) so that promotion effect did not vanish
from the closed world.

## Ownership design (report only - NOT implemented in Phase 4A)

- `civ6x10.production.MODULE_BITS` today: traits 1, policies 2, governments 4,
  pantheons 8, wonders 16.
- The CE writer arms exactly five modules
  (`s_modEnabled[5]`, mask bits 1/2/4/8/16) although the controller already
  exposes an `X10_MODULE_GOVERNORS` GameOption (parsed, currently ignored)
  and `X10_MODULE_SUZERAIN`.
- **Next owner bit: 32 = governors** (then 64 = suzerain). Phase 4B needs:
  `MODULE_BITS["governors"] = 32`, a governor manifest stream,
  `s_modEnabled[6]` + `mask |= 32` in the native writer (a native change,
  hence a DLL rebuild), and the existing owner-mask merge rule
  (transform only when ALL owning modules are enabled) reused unchanged.

## Unresolved semantic decisions for Phase 4B

- **FLAT_AMOUNT** - grievance score is a whole-point score applied for a duration (Capou Agha); score+Turns split unresolved (e.g. `CAPOU_AGHA_ADJUST_GRIEVANCES` Score=1)
- **INDIVISIBLE_COUNT** - alliance points are whole points (Khass Oda Bashi +2); integral gate candidate (e.g. `KHASS_ODA_BASHI_ADJUST_ALLIANCE_POINTS` Amount=2)
- **INDIVISIBLE_COUNT** - spy operation bonus in whole levels (Local Informants +3); integral gate candidate (e.g. `LOCAL_INFORMANTS_SPY_DEFENSE_BONUS` Amount=3)
- **CHARGES** - builder charges are whole uses (Guildmaster / vampire builds); integral gate candidate (e.g. `GUILDMASTER_ADDITIONAL_BUILDER_CHARGES_UNIT_MODIFIER` Amount=1)
- **LOYALTY** - religious pressure is a pressure rate (Cardinal Bishop); same class as identity pressure - needs review (e.g. `CARDINAL_BISHOP_PRESSURE` Amount=100)
- **PERCENT_BONUS** - percent of building production cost granted as yield (Citadel of God +25%, IncludeWonder selector); grant-on-completion semantics unresolved (e.g. `CARDINAL_CITADEL_OF_GOD_FAITH_FINISH_BUILDINGS` BuildingProductionPercent=25)
- **FLAT_AMOUNT** - religious-unit healing: percent-vs-flat unresolved (Laying on of Hands) (e.g. `CARDINAL_LAYING_ON_OF_HANDS_RELIGIOUS_HEAL` Amount=100)
- **INDIVISIBLE_COUNT** - extra unit promotions are whole promotions (Patron Saint +1) (e.g. `CARDINAL_PATRON_SAINT_PROMOTION` Amount=1)
- **INDIVISIBLE_COUNT** - extra strategic accumulation is a whole-unit flow (Defense Logistics +1) (e.g. `DEFENSE_LOGISTICS_BONUS_STRATEGICS` Amount=1)
- **INDIVISIBLE_COUNT** - attacks per turn is a capability count (Embrasure +1); scaling changes city defense structure (e.g. `CITY_DEFENDER_ADJUST_ATTACKS_PER_TURN` Amount=1)
- **MULTIPLICATIVE_FACTOR** - tourism ScalingFactor=200 (Curator): percent-vs-factor scaling unresolved (same precedent as Cristo/St. Basil's) (e.g. `CURATOR_DOUBLE_SCULPTURE_TOURISM` ScalingFactor=200)
- **MULTIPLICATIVE_FACTOR** - percent reduction of strategic-resource requirement (Black Marketeer -80%); multiplicative factor on a requirement, not a magnitude (e.g. `BLACK_MARKETEER_STRATEGIC_RESOURCE_COST_DISCOUNT` Amount=80)
- **INDIVISIBLE_COUNT** - power provided per turn is a whole-unit flow (Industrialist +1); integral gate candidate (e.g. `INDUSTRIALIST_RESOURCE_POWER_PROVIDED` Amount=1)
- **LOYALTY** - identity/loyalty gained per turn (Owls counterspies +4); same pressure class as the Toqui hold (e.g. `GOVERNOR_PROMOTION_OWLS_OF_MINERVA_3_LOYALTY_FROM_COUNTERSPY` Amount=4)
- **PERCENT_BONUS** - percent of another city's yield from spy missions (Owls +50%); percent-of-foreign-yield semantics unresolved (e.g. `GOVERNOR_PROMOTION_OWLS_OF_MINERVA_4_SPY_SUCCESS_GRANTS_SCIENCE` Percent=50)

## Traps explicitly audited

- free units/buildings/resources: `EFFECT_GRANT_UNIT_IN_CITY` (vampires),
  `EFFECT_GRANT_SPY`, `EFFECT_ADJUST_PLAYER_VALID_BUILDING`,
  `EFFECT_ADJUST_CITY_ALLOWED_IMPROVEMENT`, envoy/token grants - all
  EXCLUDED (GRANT_OBJECT).
- appointment/establishment timing: `Governors.AssignCityState`,
  `Governors_XP2.AssignToMajor`, `GovernorPromotionConditions` (0 rows) -
  structural/boolean/era gating, never scaled.
- governor titles/promotion levels: `MODIFIER_PLAYER_ADJUST_GOVERNOR_POINTS`
  (shared with traits, EXCLUDED for governors), `GovernorPromotions.Level/Column/BaseAbility` - structural.
- radius/range: `PLOT_10_TILES_AWAY_MAX_REQUIREMENTS` (MaxDistance 10,
  MinDistance 0) behind Serasker - `MODIFIER_GOVERNOR_ADJUST_DISTRICT_COMBAT_BONUS`
  is therefore SPATIAL_BUDGET/EXCLUDED, not a +10 combat write.
- charges: `EFFECT_ADJUST_UNIT_BUILD_CHARGES` (Guildmaster, vampire builds) - CHARGES, integral-gate candidates.
- district/building/unit counts: attacks-per-turn, spy levels, alliance points,
  power provided, extra accumulation, extra promotions - INDIVISIBLE_COUNT, decision-required.
- loyalty: `EFFECT_ADJUST_GOVERNOR_IDENTITY_PRESSURE` inherits the project
  Toqui stored-form hold (EXCLUDED); `EFFECT_ADJUST_CITY_IDENTITY_PER_TURN` and
  `EFFECT_ADJUST_CITY_RELIGION_PRESSURE` are held in the same class.
- thresholds in Requirements: audited, never certified as magnitudes.
- percents named alike but semantically different: treasury interest,
  ley-line faith yields, envoy modifier, district adjacency, harvest bonus,
  healing, growth, yield-per-population are additive percents;
  strategic-resource-requirement (-80%) and target-city spy yield are
  multiplicative/foreign-percent and stay decision-required.
- combat: all combat ratings use the canonical `b_k` combat transform,
  including negative values (Sanguine intimidate -5 uses the same effect as
  the live-proven Toqui transform).
- direct yields stay ADDITIVE; `EFFECT_ADJUST_BUILDING_YIELD_CHANGE` rows
  (Industrialist / Renewable Energy) inherit the Phase-3F/3G engine-integral gate.
- conditional promotion modifiers and district/plot subject requirements are
  recorded per row; the requirement itself is never scaled.
