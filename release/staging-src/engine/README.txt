X10 CE Engine (dependency mod for X10)
==========================================

This item is the ENGINE dependency for "X10 - Configurable Semantic
Multiplier". Subscribe to it together with the main X10 controller item;
you do not configure anything here.

Requirements: Windows x64, Civilization VI: Gathering Storm.
Do NOT enable another Community Extension GameCore replacement at the
same time (only one GameCore redirect can be active).
