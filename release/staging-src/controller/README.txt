X10 - Configurable Semantic Multiplier (1.0.0-rc1)
==================================================

X10 scales certified numeric game definitions by a configurable
multiplier (default x10; 0 disables the multiplier). Set X10_MULTIPLIER
to any value 0-100 (e.g. 7.3); seven per-module toggles (traits,
policies, governments, pantheons, wonders, governors, suzerain) default
ON. Whole-unit bonuses (charges, power, resources, ...) apply only on
exact integral results and otherwise keep their official values instead
of rounding.

REQUIRES the matching "X10 CE Engine" Workshop item (GameCore
replacement) and Gathering Storm. Windows x64 only. Do NOT enable
another Community Extension GameCore replacement at the same time.
This mod affects saved games.

Troubleshooting: enable logging and inspect
%TEMP%\X10Lifecycle.log after reaching the map.
